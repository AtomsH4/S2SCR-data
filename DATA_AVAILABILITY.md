# Data availability

The WorldView-2 (WV2) calibration data are publicly available from [PanCollection](https://github.com/liangjiandeng/PanCollection), specifically the full-resolution test sample `Test(HxWxC)_wv2_data_fr5.mat`. The processed Pavia University reference image is available from the [NUD_PAF repository](https://github.com/jeline0110/NUD_PAF/blob/2bbc506a982610c7b071a5c43000b84d6f7c959e/datasets/paviau.mat). The original Chikusei and Washington DC Mall datasets are available from the [University of Tokyo dataset page](https://naotoyokoya.com/Download.html) and the [Purdue University hyperspectral data repository](https://engineering.purdue.edu/~biehl/MultiSpec/hyperspectral.html), respectively. The Sentinel-2A spectral response functions (2024, version 4.0) are available from [Copernicus SentiWiki](https://sentiwiki.copernicus.eu/web/s2-documents). A curated data package containing preprocessed reference images, calibration inputs, and LR-HSI/HR-MSI observation pairs for the controlled and transferred-degradation settings, together with preprocessing documentation and file checksums, is publicly available at [S2SCR-data](https://github.com/AtomsH4/S2SCR-data).
